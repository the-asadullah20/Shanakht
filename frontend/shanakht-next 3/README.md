# SHANAKHT

Next.js frontend for the SHANAKHT CNIC extractor concept.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes

- No backend — the "Analyse" flow uses mock/sample data.
- Fonts (Fraunces, Baloo 2, Inter) load from Google Fonts via `next/font`, so an internet connection is needed on first build/dev.
- Palette, layout tokens, and component structure live in `app/globals.css` and the files under `components/`.
